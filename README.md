
# FinSight | Financial Performance & Transaction Intelligence Dashboard

## Project Overview
Developed an interactive Finance Analytics Dashboard
using Microsoft Power BI to analyze financial transactions,
customer behavior, transaction status, regional performance,
fees and taxes.

The dashboard provides a centralized business intelligence
solution for monitoring financial KPIs, analyzing YoY trends
and supporting data-driven financial decisions.

## Key Features
- 5 Financial KPIs with performance tracking
- Year-over-Year (YoY) transaction analysis
- Monthly financial transaction trends
- Success, Failed and Pending transaction analysis
- Customer segmentation across 5 business segments
- State-wise transaction performance analysis
- Analysis of 10 financial transaction types
- Gender-based customer transaction insights
- Dynamic filters and transaction-level drill-down

## KPIs
1. Total Transaction Amount
2. Total Transactions
3. Average Transaction Value
4. Total Fees
5. Total Tax
